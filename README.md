One kind, funny fortune for a houseplant — written by `main.ts` to `/output/entry.txt`.

> Your next leaf is already on its way, little one — your keeper will photograph it, frame it, and brag about it to strangers.

## Run it

```sh
node main.ts
# writes /output/entry.txt (one line, 116 characters, within the 120-character gate)
```

Node 22, standard library only, no network, no secrets, no input files — the same run always writes the same entry.
